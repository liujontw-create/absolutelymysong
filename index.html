絕對歌感AbsolutelyMySong

聽見前奏的瞬間，記憶就開始比賽——猜出歌手、歌名與年份，翻牌見真章。

開始之前

  • 主持人需要 Spotify Premium 帳號
  • 需要申請一組免費的 Spotify App（Client ID），設定大約 5 分鐘，下一步會帶你完成
  • 歌單必須是主持人自己擁有或協作的歌單，別人建立的公開歌單讀不到完整曲目

玩法規則

個人賽

  • 自由搶答，主持人聽到搶答後按下「暫停」，搶到的人 3 秒內要講出答案
  • 歌名＋歌手都要講對才算正確；年份不用講，但額外答對年份可加分
  • 答錯或超時：換下一位繼續搶答
  • 左輪模式（不需主持人）：由答題者右手邊的玩家操作手機（播放、翻牌），猜題者完全不用碰手機，不怕螢幕通知洩題。可搭配翻面手勢操作（朝下播放、朝上公布），沒有手勢就手動按按鈕

小組賽

  • 分兩隊以上，人數盡量相同
  • 一樣自由搶答（不分隊，誰搶到誰替自己隊伍回答），主持人聽到搶答按暫停，3 秒內要回答，歌名＋歌手都對才算正確
  • 每人答對一次後，這一輪不能再搶答，把機會讓給還沒過關的隊友——直到全隊每個人都至少答對一次，才算完成一輪、算一次勝利，之後重新開放全員搶答進下一輪
  • 隊友之間禁止互相提示答案

以上規則僅供參考，大家可以照自己喜歡的方式調整玩法。

隱私聲明

這個網頁是純靜態網站，沒有我們自己的伺服器，不會蒐集或上傳任何資料。 登入用的 Client ID 與 Token 只存在你瀏覽器的 localStorage 裡。 歌單與歌曲資訊即時從 Spotify 官方 API 讀取顯示，不會另外儲存， 只有最近使用過的幾組歌單名稱會留在本機瀏覽器方便下次快速選取，同樣不會上傳到任何地方。 播放控制走 Spotify Connect：這個網頁只送出「播放／暫停」這類指令給 Spotify 官方伺服器， 再由 Spotify 轉發給你選的裝置播放——音樂本身完全不會經過這個網頁，我們看不到、聽不到，也不會記錄。 唯一用到的外部資源是一個畫 QR code 用的公開程式庫，沒有任何分析或追蹤工具。

步驟 1・設定 Spotify App

這個遊戲需要你自己申請一個免費的 Spotify App 才能運作。 到 Spotify Developer Dashboard 建立一個 App，並把下面這個 Redirect URI 完整複製貼到該 App 設定的 Redirect URIs 欄位中（要一字不差，包含結尾斜線）。

如何申請 Client ID
  1. 前往 Spotify Developer Dashboard，用你的 Spotify 帳號登入
  2. 點右上角「Create app」
  3. 填寫 App name／App description（隨意填即可），Redirect URI 貼上面複製的那串
  4. 勾選「Web API」，勾選同意條款後儲存
  5. 進入剛建立的 App，點「Settings」，最上面就能看到 Client ID，複製貼到上面欄位

貼上歌單連結

玩家可以自行在 Spotify App 裡把歌加進這個歌單。貼上連結後會自動載入。
